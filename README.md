# booknow

Calendario di disponibilità e prezzi indicativi di **Le Maree di Carloforte**
(AltaMarea, BassaMarea, CountryLoft) — pubblicato su booknow.lemareedicarloforte.it.

I dati sono esportati dal booking planner (solo stati e prezzi, nessun dato degli ospiti).
Le richieste si inviano via WhatsApp e vengono confermate manualmente.
